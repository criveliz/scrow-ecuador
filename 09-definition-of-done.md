# 09 — Definition of Done

A financial feature is complete only when:

- domain rules are implemented
- authorization is enforced
- idempotency is enforced
- database transaction boundaries are correct
- audit events exist
- unit tests pass
- integration tests pass
- failure cases are tested
- secrets are not in source
- logs do not leak sensitive data
- API errors are structured
- documentation is updated

Before production:

- legal structure confirmed
- KYC/AML obligations reviewed with qualified Ecuador counsel/compliance professionals
- privacy compliance reviewed
- payment provider contract confirmed
- fiduciary/banking contract confirmed
- reconciliation procedure confirmed
- incident response procedure documented
